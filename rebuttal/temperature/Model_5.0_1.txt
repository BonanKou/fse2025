# TensorFlow Model API Knowledge Summary

## 1. Functionality Knowledge
- The `Model` class in TensorFlow's functional API is used to define a machine learning model by specifying its inputs and outputs.
- It allows for creating a new model based on an existing trained model's graph, excluding certain layers, useful for transfer learning.
- The `model.predict()` method performs predictions using real data.

## 2. Concept Knowledge
- The `Model` class integrates various layers logically, similar to other layers in TensorFlow.
- Inputs to a TensorFlow model should be formatted as Tensors, where the first dimension typically represents the batch size.
- The Functional API allows for complex model architectures by explicitly connecting different layers.

## 3. Pattern Knowledge
- A common model architecture includes an input layer, hidden layers, a global pooling layer (e.g., `GlobalAveragePooling2D`), and a final dense layer for classification.
- After training, a new model can be created by excluding the head (final layers) for transfer learning, saving its weights for further use.

## 4. Directive Knowledge
- Define and compile the model before starting the training loop to avoid creating a new model at each epoch.
- Ensure inputs are Tensors during Eager Execution.
- When creating a `Model`, the input should be an Input layer, not a tensor.
- Specify the shape of model inputs by calling `model.build()`, defining `input_shape` in the first layer, or using a real tensor to call `model(tensor)`.

## 5. Performance Knowledge
- No specific performance knowledge was provided.

## 6. Environment Knowledge
- Enable eager execution before declaring the model if using a version of TensorFlow that supports it, to train without creating a session and a scope.
- Inputs must be Tensors during Eager Execution to avoid errors.

## 7. Alternative Knowledge
- Consider using the Functional API instead of the Sequential API to avoid issues when setting `base_model.trainable = True`, which might cause the network to start learning from scratch.
